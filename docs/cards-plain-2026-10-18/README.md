# カードの説明をやさしい言葉へ

2026-10-18。公開済み。

## 対象

アプリ内の結果画面・カード詳細・カード図鑑が使う共通原稿を改稿。
全78枚の短い説明、絵の説明、正位置・逆位置の意味156件、キーワード468件、問い780件を書き直した。
「内省」「変容」「軍配」「腑に落ちる」などを、直接わかる日常の言葉へ。抽象的な行動の勧めには、話す・書く・確認する・休むなどの具体例を加えた。
死神・塔・ソードの3や10などの強い絵柄は、未来の不幸を予告する説明にしない。
詳しい画面の見出しを簡単にし、正位置・逆位置の意味を説明。カードの種類・数字・人物の補足も見直した。

カード名・ID・英語名・画像・分類・記号・点数、スコア計算、深掘りの質問キーは維持している。既存ログの形式は変更していない。
この作業で独立した読み物ページ（dist/cards/）や記事の本文は変更していない。今回の対象はアプリ内の共通カード原稿と表示。
