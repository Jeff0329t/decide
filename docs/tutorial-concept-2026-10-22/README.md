# チュートリアルにコンセプト（WHY・WHAT）を追加

2026-10-22。ローカルのみ（未コミット・未公開）。

## 目的

タロットも使い方も知らない大人に、中学生でも分かる言葉で伝える。説明を WHY → WHAT → HOW の順に並べ、広告動画と同じ言葉で統一した。

- WHY：心から納得いく決断を。
- WHAT：タロットは、心を映す鏡。（未来を当てるためではなく、自分で決めるため／占いを信じなくても使える）
- HOW：引く。決める。振り返る。

## 変更

- 最初の画面の前に WHY・WHAT の2画面を追加。各画面に「次へ」と「スキップ」。HOW の画面（今までの最初の画面）で「1枚引いて試す」。
- 練習の例を「友だちに連絡しようかな？」から「久しぶりの友人に、連絡してみる？」へ変更。
- 「ふり返る」を広告と同じ「振り返る」に統一。
- 吹き出しの文言を変更（「正解はありません」「どちらも大事なヒントです」など）。
- 最後の画面を「数日たったら、振り返ってみましょう。」にし、振り返ると決断への納得が深まることを説明。
- 本文が背景のコラージュに重なって読みにくいため、WHY・WHAT の本文に黒の下地を付けた。
- 保存の仕組み、スキップ・完了の記録、既存ログや共有リンクがあるときに表示しない条件は変更なし。
