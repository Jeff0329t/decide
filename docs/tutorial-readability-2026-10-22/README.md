# チュートリアルの改行・読みやすさ改善

2026-10-22。ローカルのみ（未コミット・未公開）。作業前の状態はコミット `5956477`。

## 目的

文章は変えずに、単語の途中での改行や、1つの段落への詰め込みをなくして読みやすくする。

## 変更

1. 文節で改行：チュートリアルの文章は `｜` で文節を、`\n` で改行を指定し、`phraseText()` が文節ごとの `span.tp`（inline-block）に変換する。「ありませ／んか」「これでよかっ／た」「まあ良かっ／た」のような単語の途中での改行がなくなる。iPhone の Safari は `word-break: auto-phrase` に対応していないため、この方法にした。
2. 見出し：WHY・WHAT・HOW と記録・振り返りの見出しを `clamp(1.7rem, 7.4vw, 2.3rem)` にそろえ、`text-wrap: balance` を付けた。「振り返ってみましょ／う。」の1文字だけ残る改行がなくなった。
3. 1文1行と強弱：
   - WHY・WHAT の本文は1つの箱にまとめ、文ごとに改行した。最後の一文（「そんなこと、ありませんか？」「カードも同じです。」）は黄色で強調。
   - HOW の練習案内は「1回、練習してみましょう。」「例：「久しぶりの友人に、連絡してみる？」」（大きく）「自分の迷いごとでもOK。練習は保存されません。」（小さく）の3段に分けた。
   - 引く・決める・振り返るの説明は、ラベルと本文を2列に分け、折り返しがラベルの下に回り込まないようにした。
   - 吹き出しは `\n\n` で段落を分けられるようにして、問いかけと補足を分けた。
4. 最後の画面：吹き出しはメインの文だけにし、「あとで知りたくなったら」の箇条書き（カードの意味・カード図鑑・使い方の見直し）を別の箱に分けた。「自分の迷いで始める」ボタンは箱の外の一番下に置き、暗い背景でも見えるように明るい色にした。

保存の仕組み、スキップ・完了の記録、表示する条件は変更なし。
