## 変更

- 「図鑑」「学ぶ」の隣に「関連記事」を追加。キーボードの左右・Home・Endでも3タブを切り替えられる。
- 提供されたWXR 7ファイルから、126本のタイトル・本文を取り込み。公開URLが確認できないため、WXRの仮リンクには飛ばさずアプリ内で読む。
- 記事の検索・5つのテーマでの絞り込み・12件ずつの追加表示・一覧への戻りを実装。検索や絞り込みは戻ったあとも維持する。
- 元の本文と見出しをテキストのブロックとして取り込む。共通のDECIDEリンク付き宣伝フッターは、アプリの一覧への戻る操作へ置き換えた。記事の一人称表現や主張は提供原稿を維持し、内容を外部資料で事実確認したものではない。
- 「学ぶ」全6レッスンは、用語の説明・友だちへ連絡する例・現在の操作に合った案内へ改稿。IDと既読状態の形式は維持。
- 記事はタブを開いたときに読み込み、失敗時はその場で再試行できる。Service Workerには原稿をキャッシュし、更新バージョンはv190。
