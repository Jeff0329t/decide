# DECIDE

「迷い続けるためではなく、決めるためのタロット」をテーマにした、スマホ対応のローカルWebアプリです。

## 使い方

ローカル確認では `dist/` をHTTPサーバーで配信してください。カード原稿と学習データを `fetch` で読み込むため、`file://` 直開きでは動作しないブラウザがあります。

記録した内容と逆位置の設定は、利用したブラウザの中にだけ保存されます。サーバーへの送信はありません。

## MVPに含まれるもの

- 入力なしの1枚引き・2枚引き（1枚引きは設定に応じて22枚または78枚の扇状デッキから選択）
- パブリックドメインのライダー＝ウェイト＝スミス版78枚
- フリップして初めて結果が見えるドロー演出（2枚引きは2枚同時にオープン）
- 設定画面で選べる34種類のカード裏面（従来の10種類を維持）
- 正位置・逆位置の基本解釈
- 78枚それぞれの短い意味、複数キーワード、絵柄のストーリー、正逆の読み方
- A.E.ウェイトの原典とRWS版の図像をもとに、現代の意思決定向けに再構成した詳しい解説
- ボタンで選ぶ深掘りと縦型Thought Map
- 深掘りが続いたときの決断促進と上限
- いつでも使える「これで決めた」
- 2枚引きでは必ずどちらかを「優勢」として理由付きで表示
- 選択肢1 / 選択肢2 / 保留、または進む / 見送る / 保留の記録
- 任意の題名・メモ・日時の保存
- 決定履歴と後日の4段階評価
- 確認画面付きの履歴削除
- 履歴一覧のカード縮小画像・意味表示と、カード別の詳細解釈
- 題名・メモ・選択・カード・意味・ストーリーを対象にした履歴検索
- 各決定へ後日書き足せる「その後のストーリー」
- LINE・X・Facebook・端末共有・コピーからのアプリ、決定結果、その後のストーリー共有
- カード画像・意味・結論が見える共有専用リンクと、画像として保存・共有できる結果カード
- カードIDだけを埋め込む短縮済みの共有リンク
- 結果画面と履歴から開けるカード詳細ポップアップ
- 履歴一覧の左スワイプ削除
- 設定でON/OFFできる、カード操作と保存時の控えめな操作音・振動
- 1枚引きのデッキ移動で細かく反応するクリックホイール風フィードバック
- 月送りと日付別表示に対応したカレンダー履歴
- 「大アルカナ／全78枚」と「正位置のみ／正逆あり」を組み合わせる2つの設定スイッチ
- APIキーなしで動くローカル深掘り提案
- JSONバックアップに加え、Obsidianで読めるMarkdownバックアップの書き出し・読み込み

## 保守の手がかり

- `dist/app.js`：画面遷移、状態、保存とイベントの接続。依然として大きいため、大規模な一括書き換えは避け、機能単位で切り出す。
- `dist/backup-format.js`：Markdown表示文と、欠落なく戻すための埋め込みデータの変換。読み込み後の検証・重複判定は `app.js` のJSON経路と共通。
- `dist/card-backs.js` と `dist/styles.css`：カード裏面の安定したID・表示名と見た目。既存IDは変更しない。
- `dist/learn.js`：図鑑と学習画面。進捗は `decide.tarot.learn.v1` に保存。
- `decide.tarot.logs.v1` と `decide.tarot.settings.v1` の既存構造は維持する。Markdown内の表示文を編集しても読み込みには反映されず、末尾のバックアップデータを使う。
- 変更後は `node --test tests/*.test.mjs` と、スマホ幅での書き出し・読み込み・カード表示を確認する。
