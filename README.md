# DECIDE

「迷い続けるためではなく、決めるためのタロット」をテーマにした、スマホ対応のローカルWebアプリです。

## 使い方

ローカル確認では `dist/` をHTTPサーバーで配信してください。カード原稿と学習データを `fetch` で読み込むため、`file://` 直開きでは動作しないブラウザがあります。

記録した内容と設定は、利用したブラウザの中（ローカルストレージ）に保存されます。ログインしない限り、サーバーへの送信はありません。

ログイン（任意・Googleアカウント）した場合は、次のオプションがあります。詳細は `dist/privacy.html` を参照してください。

- **ログの同期（UNLIMITED EDITION・任意、初期設定はOFF）**：設定でONにした場合に限り、決定ログの本文をSupabaseに保存し、別の端末と同期します（本人のアカウントからのみ読み書き可。`dist/sync.js`）。
- **プッシュ通知（任意）**：振り返り時期の通知のため、通知の宛先と振り返り前のログの `{id, remindAt}` だけを送ります。ログの中身は送りません（`dist/push.js`）。
- ログインすると、メールアドレス等のアカウント情報と、UNLIMITED EDITION購入時の購入情報（Stripe経由）がSupabaseに保存されます。

一度読み込むとService Workerがアプリ本体・コラージュ画像・カード画像をキャッシュし、オフラインでも動作します（PWA）。

## 主な機能

### 画面と導線

- 「DECIDE.」のスプラッシュ画面から「はじめる」で、1枚引き・2枚引きを選ぶクイックスタートへ進む。クイックスタートの画面上部にはアプリ名ヘッダー（黒地に黄の「TAROT FOR DECISIONS」プレート、黒縁と黄・黒の二重ハードシャドウを付けたDidotの大きな「DECIDE.」ロゴ、クリーム色の「No. 迷ったら、ここへ。」プレート）を傾けて表示し、その下に「CHOOSE YOUR DRAW」のプレートと、黒の「SOLO · 1 CARD」（1枚引き）／黄の「DUEL · A or B」（2枚引き、中央に「OR」エンブレム）のプレートで構成し、タップすると選んだ側のカードが跳ね上がって「DRAW!」のスタンプが押され、もう一方が落ちてから占いへ進む（キーボード操作・視差効果を減らす設定では即座に進む）
- 初回利用時のチュートリアル（クイックスタートの「使い方を見る」から再表示）。導入画面（ページ番号なし）のあと、DRAW（01 / 03：カードを引く）／DECIDE（02 / 03：カードの言葉をヒントに決めてログに残す。見本ログで、残る内容〈迷い・引いたカードと言葉・決めたこと（進む／見送る／保留する）・決め手や気持ちのメモ・日付〉を見せ、決めたことを試しに選ぶと「理由や気持ちは時間が経つと忘れたり書き換わったりするので、残しておくと後で結果と正直に比べられる」と記録のメリットを伝える。保存はされない）／LOOK BACK（03 / 03：後日その決断をレビューし、傾向がわかり決める精度が上がる）の3ステップで、切り絵風プレートで構成。LOOK BACKでは、DECIDEで選んだ「決めたこと」と当時の気持ちが載った見本の決定ログに◎〇△×の振り返りを試せる（保存はされない）。完了時は「ログと統計から、いつでも振り返れます」とトースト表示。導入画面のスキップは下部の「やってみる」の隣のみ（上部にはスキップを置かない）。各ステップは上部にスキップがある
- スプラッシュの「はじめる」を押すと「DECIDE.」のロゴがはがれるように飛んでからクイックスタートへ進む（視差効果を減らす設定では即座に進む）
- 下部ナビゲーション（戻る／ホーム／ログ／統計／設定）。「戻る」は直前の文脈に応じて戻り先を切り替える。選択中のタブは傾いた黄色のテープで示す
- 黒を基調とした切り絵風のエディトリアル・コラージュデザイン（画面ごとに背景コラージュを表示）
- 統計画面：サマリー／テーマ／期間（直近6か月、新しい月から表示）のタブ表示。サマリーでは決断数の下に「決断評価待ち」の件数ブロックを置き、タップで評価待ちの決断ログを一覧表示する（評価待ちは満足度リングに含めない）。満足度は「良かった／まあ良かった／どちらとも言えない／違った」を色分けしたリングと行で表示し、各行をタップするとその評価の決断ログを一覧表示する。テーマ・期間タブはランキング形式のパネルで、行をタップするとそのテーマ・その月の決断ログを一覧表示し、詳細から統計へ戻れる
- タロット図鑑と学習レッスン（「TAROT ATLAS」「LESSON」の英字キッカーを黒プレートで表示）

### 占いと決断

- 入力なしの1枚引き・2枚引き（1枚引きは設定に応じて22枚または78枚の扇状デッキから選択）
- パブリックドメインのライダー＝ウェイト＝スミス版78枚
- フリップして初めて結果が見えるドロー演出。2枚引きは「OPTION A / B」のプレートと中央の「OR」エンブレムで対比させ、「カードを開いて比べる」ボタンを長押し（約0.9秒・ゲージが満ちる間カードが震える）すると2枚が時間差でオープンする（キーボード操作・視差効果を減らす設定では通常の押下で開く）。操作説明（「2つを思い浮かべたら、カードを開きます」）は1枚引きと同じ黒プレートで、OPTION Aのプレートの上に表示（ボタンと重ならない）
- 1枚引きのデッキでは中央に来たカードを強調表示。扇状デッキの案内は黄色のテープ風プレート、操作説明と「最初に戻る」は角張った黒プレートで表示
- 「使い方を見る」ボタン、結果画面の「しっくりきた → 決める」「まだ引っかかる」ボタンも、黄・黒・明朝体・ハードシャドウのエディトリアル調で統一
- カード裏面は「星と月」デザインに統一
- 正位置・逆位置の基本解釈
- 78枚それぞれの短い意味、複数キーワード、絵柄のストーリー、正逆の読み方
- A.E.ウェイトの原典とRWS版の図像をもとに、現代の意思決定向けに再構成した詳しい解説
- ボタンで選ぶ深掘りと縦型Thought Map
- 深掘りが続いたときの決断促進と上限
- いつでも使える「これで決めた」
- 2枚引きでは必ずどちらかを「優勢」として理由付きで表示
- 選択肢A / 選択肢B / 保留、または進む / 見送る / 保留の記録
- 決断画面は「THE FINAL CALL」のキッカーと黄色プレートの見出し「今回は、どうする？」で構成。選択肢はA / B / HOLD（1枚引きはGO / PASS / HOLD）のインデックス付きの角張ったプレートで、選ぶと黄色になり「CHOSEN」のスタンプが押される。記録欄は「RECORD — 記録する」のテープ付きのクリーム色フォームで、保存ボタンは黒地に黄色の文字
- 任意の題名・メモ・日時の保存
- 結果画面からの問いかけ（インタビュー）形式の振り返り
- テーマなど、統計に使う決定メタデータの記録
- 決定履歴と後日の4段階評価

### 記録と共有

- 確認画面付きの履歴削除
- 履歴一覧のカード縮小画像・意味表示と、カード別の詳細解釈
- 題名・メモ・選択・カード・意味・ストーリーを対象にした履歴検索
- 各決定へ後日書き足せる「その後のストーリー」
- 決断後に「いつ頃結論が出そう？」で振り返り時期を選べる。時期を過ぎた決断があると、アプリを開いたときに「あの決断、その後どうですか？」と表示する（ログインしてプッシュ通知を許可した場合は、アプリを閉じていても通知が届く）
- 「納得できた！」を押すと、締めくくりの画面「迷ったら、またここへ。」を表示する（PWAは自分でアプリを閉じられないため、「このままアプリを閉じて大丈夫です」と案内する）
- LINE・X・Facebook・端末共有・コピーからのアプリ、決定結果、その後のストーリー共有
- カード画像・意味・結論が見える共有専用リンクと、画像として保存・共有できる結果カード
- カードIDだけを埋め込む短縮済みの共有リンク
- 結果画面と履歴から開けるカード詳細ポップアップ
- 履歴一覧の左スワイプ削除
- 月送りと日付別表示に対応したカレンダー履歴。評価待ちの決断がある日は黄色＋警告ストライプと「!」で強調し、評価済みの日はクリーム色で表示。月内の評価待ち件数を「AWAITING REVIEW」プレートと凡例で示す
- 履歴詳細は大きな日付プレートと「DECIDED」スタンプで表示
- 共有用の結果画像はエディトリアル調のレイアウト（黄・黒・明朝体）

### 設定とデータ

- 設定でON/OFFできる、カード操作と保存時の控えめな操作音・振動
- 1枚引きのデッキ移動で細かく反応するクリックホイール風フィードバック
- 「大アルカナ／全78枚」と「正位置のみ／正逆あり」を組み合わせた4種類のデッキプリセット
- APIキーなしで動くローカル深掘り提案
- メモ帳やObsidianで読めるMarkdown（.md）での履歴の書き出し・読み込み（旧JSONバックアップも読み込み可）
- 保存に失敗したときの通知と、定期的なバックアップのリマインド
- 設定画面は黄色の帯見出しと角張ったトグル。トースト・確認ダイアログは黒地に黄色のハードシャドウで統一

## 保守の手がかり

- `dist/app.js`：画面遷移、状態、保存とイベントの接続。依然として大きいため、大規模な一括書き換えは避け、機能単位で切り出す。
- `dist/backup-format.js`：Markdown表示文と、欠落なく戻すための埋め込みデータの変換。読み込み後の検証・重複判定は `app.js` のJSON経路と共通。
- `dist/card-backs.js`：カード裏面は `celestial`（星と月）の1種類のみ。`app.js` の `DEFAULT_CARD_BACK` で起動時に固定し、以前に保存された裏面設定も上書きする。
- `dist/styles.css`：後半の「P33: editorial collage redesign」以降がエディトリアルデザインの定義。背景コラージュ画像は `dist/assets/editorial/` に置く。
- `dist/service-worker.js`：アプリ本体・学習データ（`learn.json`）・コラージュ（WebP）・カード画像（320pxのWebP）をプリキャッシュする。480pxのカード画像は表示時に取得して上限100枚でキャッシュし、オフラインで取得できないときは320pxで代用する。本体ファイルや画像を変更したら `SHELL_CACHE` のバージョン名を必ず上げる。
- `dist/learn.js`：図鑑と学習画面。進捗は `decide.tarot.learn.v1` に保存。
- `decide.tarot.logs.v1` と `decide.tarot.settings.v1` の既存構造は維持する。Markdown内の表示文を編集しても読み込みには反映されず、末尾のバックアップデータを使う。
- 選択肢の保存値は従来どおり `選択肢1` / `選択肢2` のまま。画面・共有・バックアップの表示では `DECIDE_DECISION.choiceText`（`dist/decision-meta.js`）で「選択肢A / 選択肢B」に変換する。
- 変更後は `node --test tests/*.test.mjs` と、スマホ幅での書き出し・読み込み・カード表示を確認する。
